MARIANNE ZAMORA – PORTFOLIO

RUN LOCALLY
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html with Live Server.

EDITING
Edit js_config.js for the name, intro, contact details, skills, projects, education, experience, and certificates.
Keep all website files in this same folder. Add new images directly beside index.html and update the matching filename in js_config.js. Graphic design gallery items are managed in the graphicDesign section of js_config.js.
Do not edit generated project detail pages for ordinary content changes; they read the project data from js_config.js.

GUIDELINE FEATURES INCLUDED
- Home, About, Skills, Projects, Graphic Design Gallery, Experience, Education, CV, Contact
- Responsive layout and mobile navigation
- Dark/light theme preference saved in localStorage
- Project search across title, description, category, year, status, role, and technologies
- Category and year filters
- Interactive project detail pop-ups
- PDF CV download and online viewing
- Basic SEO metadata, robots.txt, sitemap.xml starter file
- Accessible form labels, alt text, skip navigation link, keyboard focus styles, and reduced-motion support
- Professional footer with creator name, BSIT student title, email, GitHub profile link, copyright notice, and quick navigation
- Individual project detail pages linked from each project card
- Lazy-loaded project thumbnails

IMPORTANT LIMITATIONS / BEFORE SUBMISSION
- Public hosting and HTTPS are not completed from this ZIP. Deploy the folder to GitHub Pages, Netlify, or another host, then test the public URL.
- Replace YOUR-PUBLIC-PORTFOLIO-URL in sitemap.xml, robots.txt, and the canonical/Open Graph URL metadata with the final public URL after deployment.
- The contact form uses the visitor's email application (mailto). It does not submit to a server or guarantee delivery. It also has no server-side spam protection. To meet the fully online contact-form requirement, connect and test an email form service or backend.
- No LinkedIn or GitHub profiles are linked because the creator does not have those accounts. No project source-code/demo/live-project URLs were added because none were provided or verified.
- CV details are aligned with the current website project, education, skills, and experience entries; review contact information before publishing.
- Only include personal contact details that the owner is comfortable making public.

TECH STACK
HTML, CSS, and vanilla JavaScript. No build tools or database are required for the portfolio itself.
